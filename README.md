# Sara Shanti Yoga — Website

A responsive, single-page English (UK) website for Sara Shanti Yoga in Southampton.

## Files
- `index.html` — page content, metadata, Open Graph and JSON-LD structured data
- `styles.css` — responsive layout and visual styling
- `script.js` — mobile navigation and small interactions
- `assets/yoga-beach.jpg` — supplied beach yoga photo
- `assets/yoga-park.jpg` — supplied park yoga photo
- `assets/park-yoga-*.jpg`, `hatha-*.jpg`, `stretch-forward-fold.jpg`, `meditation-*.jpg` — gallery photos (resized to max 1200px)
- `assets/cat-stretch.jpg` — photo for the "Yoga curiosities" journal box
- `favicon.svg` — simple site icon

## Before publishing (important)
1. In `index.html`, replace every `INSERT-EMAIL-HERE` with Sara's real booking email.
2. Replace the registration form link currently set to `href="#"` with the real form URL.
3. Confirm class dates and availability. Dates in the page are the supplied autumn/winter 2026 dates.
4. Confirm that the venue allows the class and whether yoga mats/equipment are provided.
5. Confirm that Sara is happy for all supplied photos to be used on the public website and that any people shown have given permission where required.
6. Add a privacy notice if the site collects personal information through a registration form, mailing list, analytics or other services. Explain who controls the data, the purpose, retention, legal basis and contact details.
7. Ensure the canonical domain `https://www.sarashanti.co.uk/` is the final domain and configure HTTPS.
8. Connect Google Search Console and submit `/sitemap.xml` after deployment.

## Local preview
Open `index.html` in a browser. For best testing, use a local static server, e.g. VS Code Live Server.
